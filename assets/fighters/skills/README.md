# 特色技能素材

每位角色各有一张 `角色-actions.png` 和一张 `角色-effects.png`，均为 1254×1254 透明 PNG。每张四行四列，行顺序为 U、I、O、N。

| 角色 | U | I | O | N |
| --- | --- | --- | --- | --- |
| DeepSeek | 鲸尾扫潮 | 摸鱼反拍 | 潜游贴贴 | 深海·大鲸落 |
| Claude | 批注飞页 | 请勿越界 | 伏笔书签 | 终章·论证完毕 |
| ChatGPT | 星环吐息 | 改写·翼返 | 追问·龙爪 | 万象·星环龙息 |

人物四列是起手、衔接、主要动作、收招。Claude 的 O 分成放置与引爆各两个姿势，ChatGPT 的 O 分成首段与追击各两个姿势。DeepSeek 的反拍架势保留第二列防守姿势，只有成功反击才使用第三列反拍。

特效四列是形成、展开、爆发、消散。运行时按实际事件选择阶段：书签待机与预警分别固定第一、二列，爆发后才播放第三、四列；飞行道具在飞行时使用第二列，实际命中或被防后才显示爆发和消散。

裁帧数据在上一级 `skills.json`。`tools/build-skill-frames.py --check` 使用仓库内 PNG 校对透明轮廓、脚底原点、比例与文件哈希，需要 Pillow。原始素材包在工作区 `outputs/character-skill-art/`，其中保留完整生成及修订提示词。重建时可以用 `--source` 指定另一份素材目录。

渲染使用单个姿势，加上围绕脚底原点的轻微位移与转角缓动。模拟帧决定姿势与攻击相位，渲染分数只细化局部变换。暂停、命中停顿和联机等待时取零渲染分数。来源与署名见 [素材署名](../CREDITS.md)。
